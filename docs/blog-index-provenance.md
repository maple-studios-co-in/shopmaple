# Recent Stories index provenance

Source: https://shop.maplefurnishers.com/blogs/recent-stories, read on 26 October 2026. The public HTML and linked theme CSS were inspected by the blog-parity agent. `apps/web/data/blog-index.json` records the ten rendered index excerpts, public Shopify image URLs, alt text and intrinsic dimensions. Excerpts are the source's truncated index copy, not generated summaries of the article bodies.

Titles, handles and publication dates remain supplied by the existing `store-content.json` import. The index sorts a copy of that article array newest-first and preserves internal article routes. It uses the source's centered italic heading, 70/30 lead card, two following half-width cards and remaining third-width cards, with a single column on mobile. Source values informed the scoped stylesheet; exact pixel parity still requires browser comparison and is not established by parser or unit tests alone.

No shared article body, policy copy, contact destination or product data was changed by this index restoration. Unknown index entries render their title and local article link without inventing an excerpt or image. The source snapshot is static; future Shopify editorial updates require a reviewed refresh.
