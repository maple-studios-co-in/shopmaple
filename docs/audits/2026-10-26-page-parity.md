# Bounded storefront parity audit — 26 October 2026

Read-only comparison of the public `https://shop.maplefurnishers.com` reference and `https://store.maplefurnishers.com`, plus the current `codex/shop-interactions-recovery` checkout. Ordinary CUA browser inspection covered desktop home, Aero PDP, Chairs collection, Contact and Recent Stories index. No forms, carts, messages, orders or payment transactions were submitted. Screenshots were inspected in the tool session; this report does not claim a retained screenshot packet or mobile/full-site certification.

The current source provenance and release records were read first. Figma campaign replacements, the authorized phone/email replacements, truthful checkout/service limitations, local policy/article imports and existing Instagram work are not treated as missing features. The Figma file was not reopened in this audit; the existing provenance records its Suggested page contexts and their raster limitations.

## Prioritized remaining findings

1. **P1 — Aero variant identity and default presentation need reconciliation.** Live `/products/aero-dining-chair` offers six choices: Nordic Ivory, Desert Taupe and Slate Modern at Price on request, followed by Deep Atlantic, Desert Taupe and Slate Modern at Rs. 23,600. The default is Nordic Ivory with an empty variant thumbnail while the blue chair gallery remains visible. The source offers three priced variants, with Deep Atlantic initially selected. This is an observed mismatch, not evidence that similarly named variants are safe to merge. `apps/api/src/catalogue-union.ts` preserves identities when no exact mapping exists; `apps/web/components/product-detail.tsx` selects an orderable variant or the first variant and falls back to gallery image zero. Resolve authoritative variant mappings and presentation for this merged product; keep unknown prices unavailable and never infer identity from labels alone. At minimum, avoid presenting unverified image/color correspondence and indistinguishable repeated options. The live title `Aero` and its description also differ from Shopify's `Aero Dining Chair` copy because union logic prefers Keeri content; reconcile the requested copy authority explicitly.

2. **P2 — Hero category links bypass the corresponding source landing pages.** The reference homepage links Sofas, Chairs and Tables to `/pages/sofas`, `/pages/chairs` and `/pages/tables`; Beds links `/collections/beds`. The deployed homepage links all four to `/collections/*`. `apps/web/components/hero.tsx` was the implementation point. The gallery/interactions agent accepted ownership of correcting this during the audit; verify its final diff and deployment before considering the live finding closed.

3. **P2 — Chairs footer contains a misleading self-link.** The deployed `/collections/chairs` says “Browse the complete chair collection on our current shop” but links back to `/collections/chairs`. This is rendered by `apps/web/components/collection-listing.tsx`, in the chairs-only preview note near its end. Remove this obsolete handoff or link to a genuinely useful local destination with accurate copy. Separately, the source `/collections/chairs` is a bespoke landing with newest arrivals, bestsellers, room merchandising and FAQ; the new URL is a generic 35-item grid. The bespoke local page already exists at `/pages/chairs`. This route distinction is documented historical adaptation, but it remains a parity decision for old inbound URLs.

4. **P2 — Recent Stories reverses source order and omits index excerpts.** The reference `/blogs/recent-stories` starts with “How to Measure Furniture Before Ordering Online” and shows an excerpt for each article. The new index starts with “Space-Saving Furniture Ideas for Small Homes” dated 6 June 2026, followed by the 13 June article. `apps/web/app/blogs/[blog]/page.tsx` maps imported order directly and renders date/title/link only. Sort a copied array newest-first and preserve source excerpts if matching the original index is required. The current title is left-aligned and upright above bordered two-column cards; the source screenshot has a centered italic title and a different editorial layout. Source image areas had not visibly loaded in the screenshot, so this audit makes no claim about missing source thumbnails.

5. **P2 — Review, subscription, account and returns service parity remains intentionally incomplete.** Aero source shows “Be the first to write a review” and “Write a review”; the new PDP shows “No reviews yet” plus Contact Support (`components/product-detail.tsx`). Newsletter reports unavailable (`components/home-forms.tsx`), account is a support page (`app/account/page.tsx`), and returns save an enquiry (`app/pages/returns/page.tsx`). These truthful fallbacks are preferable to invented success but do not satisfy full service equivalence. Separate their integration work from visual restoration and keep checkout disabled. The source signup popup offering 10% off was visible on first home visit; this subscription flow is also not reproduced.
