# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Next.js/React/TypeScript frontend and owned Express/Prisma/PostgreSQL commerce backend in one repository. Keeri is the product source. User explicitly excluded Medusa and selected the existing Shopify payment gateway.

## Product Purpose
An independent Maple Furnishers ecommerce site, preserving the existing shop UI and improving image/content delivery.

## Users
People browsing and purchasing Maple furniture, including visitors making custom furniture enquiries. This audience follows the existing storefront; no new research claims are made.

## Capabilities and Constraints
Catalogue, variants, cart and ultimately gateway checkout and Keeri order handoff. Preserve made-to-order enquiry distinctions. Initial implementation is a development preview, not a live checkout.

## Brand Commitments
The user requires the same exact visible UI as shop.maplefurnishers.com, including mobile behavior. Do not redesign the brand.

## Evidence on Hand
Published theme export retained locally outside version control. Live storefront inspected on 25 October 2026. Current preview catalogue is a dated Shopify snapshot; it is not a live Keeri sync.

## Open Decisions
Exact existing payment provider and credentials, authenticated Keeri export/reservation contract, production shipping rules and deployment.
