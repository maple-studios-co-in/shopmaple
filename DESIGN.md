# Maple storefront visual reference

Authority: the user's existing shop.maplefurnishers.com, inspected 25 October 2026. This is preservation work, not a new visual concept.

- Warm cream canvas #f4f2ec; burgundy #741a14; green imagery/category tiles.
- Manrope body, Newsreader headings, Red Hat Display accents.
- At 1280px the announcement is 42px high, main header about 108px, category navigation about 39px.
- Centred existing Maple logo; utility links left; search/account/favourites/cart right.
- Hero starts with 20px outer gutter and 24px top gap: half-width workshop video, half-width two-by-two image category tiles. Cards use 16px radii. Hero roughly 500px high.
- Category text is upper-left, arrow upper-right; white serif heading and restrained sans-serif price line.
- Product grids retain generous imagery and minimal chrome.
- Mobile adapts columns and navigation while retaining content, focus states and readable labels.
- Preview status must be explicit; never imply checkout or live stock has been verified.
